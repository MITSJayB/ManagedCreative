# Managed Creative website

Static single-page site served by Cloudflare Workers. Edit the pages in `build.mjs` and `src/site.css`, run `node build.mjs`, and commit `public/`. Pushing to `main` deploys once the repo is linked in Cloudflare Workers Builds.

Core copy: Notion, "Managed Creative — Website Copy". Branding, marketing and supporting page copy is new draft copy. Logos: Managed Creative logo pack.
